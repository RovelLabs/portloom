# Performance Targets & Measurement Methodology

## 1. Измеримые цели производительности V1

| Метрика | Целевой показатель (V1) | Обоснование |
|---|---|---|
| **Холодный запуск ядра (Cold Start)** | < 350 мс | Мгновенный отклик при запуске из консоли или ярлыка |
| **Потребление RAM в режиме ожидания (Idle Memory)** | < 45 МБ | Незаметная работа в фоновом режиме на ноутбуках и ПК |
| **Задержка проксирования (Proxy Latency Overhead)** | < 1.8 мс на запрос | Незаметное влияние на скорость отклика локальных dev-серверов |
| **Время сканирования портов (Port Scan Duration)** | < 120 мс | Плавное обновление таблицы портов без зависания UI |
| **Генерация сертификата домена (Cert Minting)** | < 250 мс | Мгновенный 1-клик выпуск сертификата для нового домена |
| **Размер бандла клиентской части (Web/UI Assets)** | < 1.2 МБ (gzipped < 350 КБ) | Нулевая зависимость от внешнего интернета, быстрая отрисовка |

---

## 2. Методология измерений

1. **Proxy Latency Overhead:**
   - Замеряется через сравнение времени отклика (`ttfb`) прямого обращения к `http://127.0.0.1:3000/api/health` и через шлюз `http://127.0.0.1:24224/proxy/...` при 100 последовательных HTTP-запросах.
2. **Idle Memory:**
   - Измеряется через Windows Performance Counters (`WorkingSet64` и `PrivateMemorySize64` процесса Node/Portloom).
3. **Port Scan Duration:**
   - Замеряется встроенным таймером высокой точности `process.hrtime.bigint()` от начала выполнения системного запроса до завершения парсинга таблицы сокетов.

---

## 3. Архитектурные оптимизации

- **Кэширование безопасных контекстов TLS (SNI Cache):** Сертификаты X.509 создаются один раз и сохраняются в LRU-кэше в памяти. Повторные TLS-хэндшейки не тратят ресурсы CPU на парсинг PEM-ключей.
- **Потоковая передача данных (Zero-Copy Stream Piping):** Запросы и ответы передаются через нативные Node.js Streams (`req.pipe(proxyReq)`), предотвращая накопление мусора в V8 heap.
- **Ленивая загрузка криптографии:** Тяжелые криптографические операции генерации ключей выполняются только при запросе нового сертификата, не замедляя старт приложения.
