# Issue & Feature Backlog

Бэклог исследовательских и будущих задач для открытого сообщества контрибьюторов:

### Инфраструктура и упаковка
- [ ] **Windows MSIX / Winget Package:** Создание официального манифеста для пакетного менеджера Windows (`winget install portloom`).
- [ ] **Tray Minimization Mode:** Сворачивание в системный трей Windows с всплывающими уведомлениями при конфликтах портов.
- [ ] **Portable .zip Distribution:** Подготовка самодостаточного zip-архива с portable-версией, не требующей прав администратора.

### Сеть и безопасность
- [ ] **Firefox NSS Store Auto-import:** Автоматическое добавление локального CA в базу сертификатов браузера Mozilla Firefox (`cert9.db`), так как Firefox использует собственное хранилище отдельно от Windows CryptoAPI.
- [ ] **HTTP/3 (QUIC) Local Termination:** Экспериментальная поддержка локального HTTP/3 на базе UDP-сокетов.

### Интерфейс и пользовательский опыт
- [ ] **Har Export:** Возможность выгрузки сессии захваченного трафика в стандартный формат `.har` для анализа в Chrome DevTools.
- [ ] **GraphQL Payload Formatter:** Автоматическое распознавание GraphQL запросов в инспекторе трафика с подсветкой синтаксиса операторов и переменных.
