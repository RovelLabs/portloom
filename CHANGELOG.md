## [1.0.0] - 2026-09-13

### Added
- **Live Port Matrix:** High-speed scanning of Windows TCP listening sockets with PID, process name, memory usage, and 1-click process termination.
- **Hosts File Manager:** Safe parser and serializer for `C:\Windows\System32\drivers\etc\hosts` with profile support, automated backups, and DNS cache flushing.
- **Local Root CA & SSL Hub:** Self-sovereign generation of local Root CA and dynamic X.509 leaf certificates with Subject Alternative Names (SAN).
- **Dynamic Reverse Proxy:** Local HTTP/HTTPS reverse proxy with SNI routing, path prefix forwarding, and WebSocket/HMR pass-through.
- **Webhook & Traffic Inspector:** In-memory live request capture, headers inspection, formatted JSON viewing, cURL command generator, and offline mock response engine.
- **Bilingual Interface:** First-class Russian (RU) and English (EN) localization with zero translation artifacts and full Cyrillic path support.
- **Official Documentation & Website:** Built-in portal, landing page, brand kit, and developer guides.
