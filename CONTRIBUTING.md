# Contributing to Portloom

Спасибо за ваш интерес к развитию Portloom! 
Мы стремимся создать надежный, быстрый и удобный инструмент для разработчиков со всего мира.

---

## 🛠️ Настройка окружения разработки (Local Setup)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/RovelLabs/1.git
   cd portloom
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите в режиме разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере:
   ```
   http://localhost:24224
   ```

---

## 🧪 Запуск проверок и тестов

Перед созданием Pull Request обязательно убедитесь в прохождении тестов:
```bash
# Проверка типов TypeScript
npm run lint

# Запуск юнит- и интеграционных тестов
npm test

# Сборка продакшен-бандла
npm run build
```

---

## 📝 Стандарты кода и коммитов

- **TypeScript:** Строгая типизация (`strict: true`), избегайте `any`.
- **Локализация:** Любая новая функциональность должна содержать строковые константы как на русском (`ru`), так и на английском (`en`) языках.
- **Поддержка Windows:** Код всегда должен корректно работать с путями, содержащими пробелы и кириллицу.
- **Conventional Commits:**
  - `feat:` новая функциональность;
  - `fix:` исправление ошибки;
  - `docs:` изменения в документации;
  - `test:` добавление тестов;
  - `perf:` оптимизация производительности.
