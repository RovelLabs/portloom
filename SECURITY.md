# Security Policy

## Поддерживаемые версии

| Версия | Поддержка безопасности |
|---|---|
| 1.0.x | :white_check_mark: Поддерживается |
| < 1.0 | :x: Устарела |

## Как сообщить об уязвимости

Безопасность пользователей и разработчиков — высший приоритет Portloom.

Если вы обнаружили потенциальную уязвимость:
1. **НЕ создавайте публичный Issue на GitHub.**
2. Воспользуйтесь функцией **GitHub Private Vulnerability Reporting** в репозитории проекта (вкладка Security → Report a vulnerability).
3. Либо отправьте подробный отчет на защищенный адрес поддержки проекта: `security@portloom.org`.

В отчете, пожалуйста, укажите:
- Тип уязвимости (например, Path Traversal, Privilege Escalation);
- Шаги для воспроизведения и Proof of Concept;
- Потенциальное воздействие на систему;
- Предлагаемые способы устранения (если есть).

Мы обязуемся предоставить первичный ответ в течение 48 часов и подготовить исправление до публичного раскрытия.
