Локальный шлюз
разработчика под Windows

Portloom связывает воедино управление портами, профили hosts, 1-клик выпуск доверенных локальных SSL-сертификатов и высокоскоростной reverse proxy с инспектором вебхуков.

Начать бесплатно GitHub Repository
$ npx portloom

Хватит мучиться с сетевым окружением на Windows

Сравните привычный сценарий и разработку с Portloom

❌ До Portloom
  • ⚠️
    Ошибка EADDRINUSE: поиск PID через netstat -ano и ручной taskkill в терминале.
  • ⚠️
    Браузер блокирует Web Crypto, Service Workers и TMA из-за отсутствия HTTPS.
  • ⚠️
    Редактирование hosts через Блокнот от Администратора, поломка комментариев и синтаксиса.
  • ⚠️
    CORS-ошибки при связке React (:5173) и API (:8000), либо запуск тяжелого Docker.
  • ⚠️
    Необходимость платных облачных туннелей (ngrok) для просмотра вебхуков.
✨ С Portloom
  • ✅
    Интерактивная таблица всех портов: освобождение любого порта в 1 клик.
  • ✅
    Автоматический выпуск доверенного SSL (Root CA) для любых локальных доменов.
  • ✅
    Визуальный менеджер hosts с профилями проектов и автоматическими бэкапами.
  • ✅
    Шлюз reverse proxy объединяет фронтенд и бэкенд на едином красивом домене.
  • ✅
    Локальный инспектор запросов в реальном времени с поддержкой оффлайн-моков.

Всё необходимое в одном приложении

Монолитная функциональность, нулевой оверхед, бескомпромиссная надежность.

⚡

Матрица портов Windows

Мгновенное сканирование всех слушающих сокетов. Отображение PID, имени исполняемого файла, памяти и защита системных служб Windows от случайного убийства.

🔒

1-Клик доверенный SSL (Root CA)

Автономный генератор локального Root CA и выпуск X.509 сертификатов с SAN для любых доменов (*.local, localhost). Автоматическая интеграция с хранилищем Windows.

🌐

Менеджер профилей Hosts

Безопасная атомарная запись в C:\Windows\System32\drivers\etc\hosts с созданием резервных копий и мгновенным сбросом DNS-кэша через ipconfig /flushdns.

🔀

Динамический Reverse Proxy

Маршрутизация https://app.local → :5173 и https://app.local/api → :8000 с прозрачной поддержкой WebSocket (Vite HMR) и авто-нормализацией заголовков CORS.

📡

Инспектор вебхуков и трафика

Кольцевой буфер запросов в реальном времени. Инспекция заголовков, форматированный JSON полезной нагрузки, расчет задержки в миллисекундах и экспорт в cURL.

🛡️

0% телеметрии и 100% оффлайн

Работает полностью изолированно (Air-Gapped). Без аккаунтов, без токенов, без внешних CDN и облачных сервисов. Ваши данные никогда не покидают ваш ПК.

Установка и запуск

Выберите удобный для вас способ запуска на Windows

🚀 Мгновенный запуск (NPX)
Запуск без постоянной установки через Node.js
npx portloom
Требуется Node.js >= 18
📦 Глобальная установка (NPM)
Доступ к утилите из любого терминала Windows
npm install -g portloom
portloom
Добавляет команду portloom в PATH
